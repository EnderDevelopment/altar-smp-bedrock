# Altar SMP Bedrock Plugin

The Altar SMP Bedrock Plugin is a Minecraft plugin designed to replicate the popular Java SMP Altar SMP plugin from season 2. This plugin aims to provide a similar experience for Bedrock Edition players, including the famous altar mechanics and other unique features from the original SMP. The plugin is built using Java and is compatible with Minecraft Bedrock Edition servers.

## Install

1. Download the plugin JAR file from the GitHub repository.
2. Place the JAR file in the `plugins` folder of your Minecraft Bedrock Edition server.
3. Start or restart your server to load the plugin.

## Use

1. Once the server is running, players can use the `/altar` command to receive a welcome message and access the altar mechanics.
2. Follow the in-game instructions to participate in the Altar SMP events and activities.
